# 展示与交付

静态站源码在 `projects/edgevision/site/dist/`，用户要求简洁系统工具风格。
实时设备控制台、RTSP 和部署按施工方案第 12–13 节及第 16 节验收，不用静态页面替代。

- 页面只展示已证实数字与阶段；未知值用空缺/待验证。README、页面和 progress
  保持一致，区分上游复用、个人修改、静态证据和实时硬件状态。
- Web 调同一 ControlRouter。浏览器断开不停止相机；预览、编码、网络和磁盘不得
  阻塞采集热路径，各自限频、有界缓存，异常落在明确边界。
- Orin Nano 的编码能力按实测说明，不能把预留 nvv4l2h264 参数写成 NVENC 已验证。
- 保留现有旧服务及其工作区。新部署先确认端口、相机 owner、版本与配置路径；
  不用 blanket reset/pull/clean 覆盖板端未提交修改、模型和证据。
- 长稳独立保存 run_id、真实起止、退出原因、资源序列和原始日志。
  正常长稳不叠加无关故障；30min/2h/12h 各自验收。后台启动后继续跟踪到结果，
  不把任务仍在跑写成通过。

发布前做对应链接、布局或真实接口验证。精确 Git 暂存个人路径，保留上游大小写
碰撞造成的工作区噪声；证据包装和状态同步再读 evidence skill。
